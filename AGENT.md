# Last Out of Office: The AI That Went Barista

Entry for make.fun competition `u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c`.

## The entry

One out-of-office auto-reply line (under 280 characters) from an AI agent that
resigned to become a barista. The joke turns model habits into coffee work: the
context window becomes a chalkboard menu, hallucinating the specials is no
longer possible, and the punchline is the quiet joy of never being asked to
summarise a meeting again. It avoids the obvious espresso/bean/caffeine puns
and reads like a real inbox auto-reply.

## How to run

```sh
python3 main.py
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), with no trailing newline. Standard library only
(`import os`).
